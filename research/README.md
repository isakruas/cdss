# CDSS Research Validation

This directory contains reproducible research tooling for scientific validation
of the CDSS modem implementation. The tooling drives the public `cdss simulate`
command and records the exact binary, campaign grid, random seeds, channel
profiles, and per-frame outputs used for analysis.

The repository-root `Makefile` intentionally remains limited to normal project
operations such as build, test, install, and CLI execution. Monte Carlo
campaigns, Python environments, and validation figures live here.

## Setup

Create the local Python environment and install plotting dependencies:

```bash
cd research
make venv
```

Build the Fortran modem from the same research workflow:

```bash
make build-cdss
```

## Monte Carlo Campaign

Run the single release validation flow and generate the PDF report:

```bash
make release
```

This is the only supported research workflow. It runs the full release
preset and emits the final validation PDF from the same campaign.

Useful overrides:

```bash
make release WORKERS=8 OMP_THREADS=1
make report INPUT=mc_results/simulate_mc_YYYYMMDD_HHMMSS/results.jsonl
make plots INPUT=mc_results/simulate_mc_YYYYMMDD_HHMMSS/results.jsonl
```

## Channel Profiles

| Profile | Validation purpose |
|---|---|
| `aligned_awgn` | Baseline TX/channel/RX over AWGN with known frame alignment. |
| `sync_awgn` | AWGN with guard padding and receiver preamble search. |
| `cfo_drift` | Preamble search under carrier offset and linear frequency drift. |
| `tone` | Preamble search with a continuous-wave interferer. |
| `clock` | Preamble search with sample-clock error. |

Profiles using `--sync-search` validate acquisition and phase alignment before
decoding. The aligned profile remains useful as a controlled decoder baseline.

## Campaign Outputs

Each campaign directory under `mc_results/` contains:

| File | Purpose |
|---|---|
| `manifest.json` | Campaign configuration, binary path, binary SHA-256, Python/platform metadata, profiles, seeds, and grid size. |
| `results.jsonl` | One JSON record per simulated frame. This is the primary auditable dataset. |
| `summary_by_profile_payload_snr.csv` | Main numeric performance table by profile, payload size, and SNR. |
| `summary_by_profile_payload.csv` | Aggregate table by profile and payload size. |
| `summary_by_profile.csv` | Aggregate table by channel profile. |
| `failures.csv` | Nonzero command exits or JSON parsing failures. |
| `paper_summary.md` | Human-readable campaign report generated by the runner. |

## Scientific Use

For review and release validation, preserve the full campaign directory with the source
revision, compiler version, and binary hash. The generated reports provide
statistical evidence for the measured parameter grid; they do not claim
performance for unmeasured hardware, fading channels, oscillator conditions, or
traffic patterns.
